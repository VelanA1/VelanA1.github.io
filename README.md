# Velan Arun — Portfolio Website

A fast, responsive, single-page personal portfolio built with plain HTML and CSS. It links to five public machine-learning and quantitative-research GitHub repositories.

## Preview locally

Open `index.html` in a browser. No development server, build tools, account, or dependencies are required.

## Publish free using GitHub Pages

1. In GitHub, create a **public** repository named **`VelanA1.github.io`** under your `VelanA1` account (if it doesn't already exist).
2. Open that repository, choose **Add file → Upload files** and upload **`index.html`** and **`favicon.svg`** from this folder (you may also upload this README). Commit the changes.
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then **Save**.
4. Once GitHub Pages finishes deploying, the expected site URL is **https://velana1.github.io/**. This URL is not live until you publish.
5. Add the website link to your resume, LinkedIn profile, and GitHub profile bio.

If you choose a repository name other than `VelanA1.github.io`, the Pages address normally includes that repository name as a path segment.

## Personalization

- Update the intro and project descriptions in `index.html` as you complete or validate new work.
- To add a resume button, place a public-safe PDF in the same folder and link it from `index.html`. Review contact information before posting your resume publicly.
- If you switch GitHub or LinkedIn usernames, replace the profile links throughout `index.html`.

## Design / accessibility

- Responsive layout, keyboard focus states, semantic headings and navigation, reduced-motion support.
- No JavaScript, analytics, cookies, third-party fonts, or external assets required.
- All project links go to their corresponding GitHub repositories. Scientific conclusions and limitations belong in the repository READMEs.
